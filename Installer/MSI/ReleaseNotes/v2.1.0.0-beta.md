# MLAstroRPA+TPPA v2.1.0.0-beta

Pre-release of v2.1.0.0 — the merged **MLAstroRPA + TPPA** plugin with **PC control over Wi-Fi (WebSocket)**.
The installer reports version `2.1.0.0` (Windows Installer has no `-beta` suffix).

**Requires device firmware 1.3.0 or newer**

## ✨ Highlights
- **Wireless connection** (Serial or Wireless) — `MLAstroRPA.local` or the device IP; TPPA auto-adjustment also works over Wi-Fi
- **Complete text <-> JSON translator** — every command and telemetry token behaves the same over USB and Wi-Fi, settings sync two-way
- **Log & dock parity with the Web UI** — web-style log table (keyword colours, newest on top, 50 lines), RESET ERROR / Export CSV / Clear, `alert` shown as NINA toasts
- **Alarm panel** — `CmdRf` decoded into readable warnings, newest on top; CLEAR clears only the displayed history
- **Jog / relative / soft-limit safety** — jog release decelerates via `stopMove`, jog buttons lock on a soft limit and re-enable, relative mode stays on
- **Relative distance by keyboard** — type D/M/S directly (degrees 0–5, minutes/seconds 0–59, Enter sends)
- **Align errors shared instantly** — Enter in an Az/Alt field sends D/M/S + direction and the device broadcasts it to every WebSocket client
- **UI restyle** — rounded-triangle movement pad, circular speed buttons, square STOP, circular FORCE STOP in a square frame, leaner relative steppers
- **CONNECTION tab cleanup** — fixed 115200 8N1 (no Data Bits / Parity / Stop Bits / Refresh Ports), Reset ESP32 next to Connect
- WiFi/AP settings and passwords can be saved over Wireless

## 🔧 Fixed
- Reset ESP32 over Wireless did nothing (missing `reboot` mapping, `releaseControl` sent too early)
- Passwords are no longer broadcast — 👁 fetches them from the device; a blank box on save keeps the current value
- Settings mirrored from telemetry no longer keep stale values or fabricated defaults
- Telemetry keys were parsed as alarms — now only `ERROR:` lines are
- Align D/M/S changed over Serial were not broadcast — the Web UI needed a page refresh
- Align direction toggle over Wireless

## ⚠️ Notes
- Wi-Fi password: press 👁 to fetch it from the device; a blank box on save keeps the current value
- An empty AP IP / subnet is auto-repaired to `192.168.4.1` / `255.255.255.0` by firmware 1.3.0
