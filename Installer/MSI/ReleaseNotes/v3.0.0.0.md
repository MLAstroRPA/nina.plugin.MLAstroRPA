# MLAstroRPA v3.0.0.0

First standalone release of the MLAstroRPA plugin: it controls the MLAstro Robotic Polar Alignment hardware from N.I.N.A. over USB serial or Wi-Fi, and the same installer also sets up the Three Point Polar Alignment plugin that drives the correction over the NINA message broker.

**No firmware update required** — works with the current MLAstro RPA controller firmware, over the cable or the WebSocket link.

## ✨ Highlights
- **One installer, two plugins** — sets up MLAstroRPA 3.0.0.0 and Three Point Polar Alignment 2.2.8.0 side by side under `%LOCALAPPDATA%\NINA\Plugins\3.0.0\`.
- **Runs the correction for Three Point Polar Alignment** — measurements, axis moves, capture windows, pause, stop and cancel all go through the message broker.
- **Installs next to MLAstroRPA+TPPA** — own PluginId, MSI UpgradeCode, namespaces and resource keys, so the MLAstroRPA plugin and the merged MLAstroRPA+TPPA plugin can be installed at the same time without one overriding the other's pages.
- **Options tabs are now** CONTROL / HARDWARE SETTING / SOFTWARE SETTING / CONNECTION.
- **Broker log carries a direction** — `RPA -> TPPA` (sent) or `TPPA -> RPA` (received), with a colour legend.

## 🔧 Fixed
- STOP / FORCE STOP stops the axes before the session is cancelled, exactly once, and the aborted move is no longer reported as a hardware fault.
- A pause no longer lets a planned move start.
- Losing the firmware link (serial or wireless) cancels the TPPA session instead of leaving it waiting.
- Polled telemetry no longer overwrites the azimuth/altitude inputs while they are being edited.
- Commands dropped because the link is not connected are logged instead of failing silently.

## ⚠️ Notes
- Requires N.I.N.A. 3.1.2.9001 or newer; the package installs both plugins per-user, so close N.I.N.A. before installing.
- Settings start from defaults: the plugin has a new identity, so the COM port, the correction options and the TPPA assignment have to be set again after the upgrade.
- If the merged MLAstroRPA+TPPA plugin is installed, remove it first - the TPPA wizard would otherwise be installed twice.
- Manual update: copy `NINA.Plugins.MLAstroRPA.dll` into `...\3.0.0\MLAstroRPA\` and `NINA.Plugins.PolarAlignment.dll` into `...\3.0.0\Three Point Polar Alignment\`. Do not put them into the MLAstroRPA+TPPA folder.
