# MLAstroRPA+TPPA v2.2.1.0

Bug-fix release for connection status reporting and wireless link stability.

**Requires device firmware 1.7.0 or newer**

## 🔧 Fixed
- AP/STA status indicators now reflect PC connection and disconnection states.
- WebSocket link watchdog now disconnects stale plugin connections after silence.

## ⚠️ Notes
- No breaking changes.
- Close NINA before installing the MSI.
- Existing Serial and Wireless configuration is preserved.
